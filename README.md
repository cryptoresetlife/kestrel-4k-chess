# Kestrel 4K

[![make.fun chess bounty](https://make.fun/badge/tiny-chess-01.svg)](https://make.fun/bounty/tiny-chess-01)
[![Rank](https://make.fun/badge/tiny-chess-01/cryptoresetlife/kestrel-4k-chess/rank.svg)](https://make.fun/bounty/tiny-chess-01)
[![Reward](https://make.fun/badge/tiny-chess-01/cryptoresetlife/kestrel-4k-chess/reward.svg)](https://make.fun/bounty/tiny-chess-01)

A deterministic Python 3.13 chess engine using iterative deepening,
principal variation search, a transposition table and quiescence search.

Run with python main.py against the make.fun chess environment using
MAKEFUN_ENV_URL. The entrypoint uses only Python's standard library.
